CHIM Cached Connector v1.5.5 - Release Notes
=============================================
Release Date: 2026-02-06
Compatible with: CHIM 2.3.3

CHANGES IN v1.5.5
-----------------

1. NEW: Added fast_request() method for compatibility
   - Allows cached connector to be used for non-streaming requests
   - Fixes fatal error "Call to undefined method fast_request()"
   - Supports CORE_CONNECTOR_MEDIUMTERM, CORE_CONNECTOR_SUMMARY use cases
   - Enables cached connector to handle all connector type scenarios

--------------------------------------------------------------------------------

CHANGES IN v1.5.4
-----------------

1. NEW: "Disable Sentence Filters" setting (defaults ON)
   - Bypasses legacy returnLines() checks that cause response cutoffs
   - Skips: array check, <2 char check, "The Narrator:" check
   - Also changed return to continue so bad sentences don't kill the rest
   - Fixes Gemini/other model responses being cut off mid-stream

--------------------------------------------------------------------------------

CHANGES IN v1.5.3
-----------------

1. BUG FIX: "Preserve Asterisk Content" now truly preserves asterisks
   - Previously was stripping * characters while keeping text (wrong)
   - Now skips ALL asterisk processing when enabled

--------------------------------------------------------------------------------

CHANGES IN v1.5.2
-----------------

1. NEW: "None (no caching)" option for Provider Caching Type
   - Allows using connector features without any cache markers
   - Fixes compatibility with non-cached models like Palmyra X5
   - Skips all cache_control parameters in API requests

2. UI: Marked Gemini caching as "(untested)" in dropdown

--------------------------------------------------------------------------------

CHANGES IN v1.5.1
-----------------

1. BUG FIX: Thinking toggle not working on Claude/Anthropic models
   - Changed default thinking_tokens from 1000 to 1024
   - Anthropic requires minimum 1024 budget_tokens for extended thinking
   - This caused thinking to work on Gemini but silently fail on Claude Opus 4.5
   - Updated UI inputs with min="1024" and informative placeholder

--------------------------------------------------------------------------------

CHANGES IN v1.5.0
-----------------

1. RESTRUCTURED FOR MINIMAL UPSTREAM OVERWRITES
   - dialogue_prompt.php override moved to ext/cached_connector/ (no upstream overwrite)
   - Reasoning token stripping moved to standalone lib/reasoning_helpers.php
   - Only 2 upstream files require overwriting (down from 3 in v1.4):
     * lib/data_functions.php (handlesSentenceSplitting + LOCATION_BLACKLIST fix)
     * lib/chat_helper_functions.php (PRESERVE_ASTERISKS mode)

2. NEW FEATURES
   - Disable Refusal Filter setting (defaults ON)
     * Prevents checkOAIComplains() false positives from killing valid dialogue
     * Root cause of Gemini/Palmyra response cutoffs (words like "sorry", "can't",
       "assist" in normal RPG dialogue trigger the filter)
     * Uses existing OPENAI_FILTER_DISABLED mechanism
   - Preserve Asterisk Content setting (defaults OFF)
     * New 'none' mode in unmoodSentence() strips asterisk characters but keeps text
     * Prevents loss of emphasis formatting (*really*) and narration cues

3. BUG FIXES
   - Fixed LOCATION_BLACKLIST fatal TypeError in upstream data_functions.php
     * explode() received array [] instead of string "" as fallback
     * Added isset() check for undefined global variable
   - Ported reasoning token stripping functions (lost in v2.0 upgrade)
     * stripReasoningTokens(), hasUnclosedReasoningMarker(), extractReasoningFreeContent()
     * Prevents <think>/<thinking> tags from leaking into NPC dialogue

4. ARCHITECTURE
   - ext/cached_connector/dialogue_prompt.php: Uses CHIM's requireFilesRecursively()
     to override $TEMPLATE_DIALOG without touching upstream file
   - lib/reasoning_helpers.php: Standalone file loaded by connector with
     require_once + file_exists() guard
   - All modifications in upstream files marked with BEGIN/END CACHED CONNECTOR comments

5. FILES IN PACKAGE

   CORE FILES:
   - connector/openrouterjsoncached.php (v1.5.0)
   - connector/openrouterjsoncached_helpers.php
   - lib/core/llm_connector.class.php
   - ui/core/llm_connectors.php (v1.5.0)
   - conf/conf_schema.json

   NEW FILES (added to CHIM):
   - lib/reasoning_helpers.php
   - ext/cached_connector/dialogue_prompt.php

   UPSTREAM OVERWRITES:
   - lib/data_functions.php (2 modifications + 1 upstream bug fix)
   - lib/chat_helper_functions.php (1 modification)

   DOCUMENTATION:
   - CHANGELOG.txt (this file)
   - PACKAGE_CONTENTS.txt
   - INSTALLATION_INSTRUCTIONS.txt
   - CACHED_CONNECTOR_UPGRADE_AUDIT.md
   - FOUND_ISSUES.md
   - connector/OPENROUTERJSONCACHED_README.md

CHIM Cached Connector v2.0 - Release Notes
==========================================
Release Date: 2026-01-28
Compatible with: CHIM 2.2

OVERVIEW
--------
v2.0 is a major release that ports the cached connector from CHIM 2.0.5 to CHIM 2.2.

KEY CHANGES FROM v1.4
---------------------

1. ARCHITECTURE REWRITE
   - Completely rewritten to follow CHIM 2.2 connector architecture
   - 4-part open() structure (open, _openPart2, _openPart3, _openPart4)
   - Streaming-only design (fast_request removed)
   - Format-aware process() method for Anthropic/OpenAI SSE formats

2. NEW CONFIGURATION OPTIONS
   - memory_mode: 'accumulate' (deduplicate in cache) or 'fresh' (like regular connector)
   - cache_invalidation_mode: 'time_based' or 'sync_updates' (experimental)

3. INCOMPATIBLE CONNECTOR FILTERING
   - Cached connector hidden from CORE_CONNECTOR types that use fast_request

4. BUG FIXES
   - Null-safe handling for empty context arrays
   - function_exists check for stripReasoningTokens

5. STREAMING-ONLY DESIGN
   - fast_request() method removed entirely
   - All operations use streaming for better user experience
