CHIM Cached Connector v1.3.5 - Release Notes
============================================
Release Date: 2026-01-21
Compatible with: CHIM 2.0.3

OVERVIEW
--------
v1.3.5 restructures the package into CORE and ADDITIONALS for easier
maintenance when HerikaServer updates. The UI now conditionally shows
features based on which files are installed.

KEY CHANGES
-----------

1. CORE/ADDITIONALS SPLIT

   Package now clearly separated into:

   CORE FILES (6 files - minimum required):
   - conf/conf_schema.json
   - lib/core/llm_connector.class.php
   - ui/core/llm_connectors.php
   - connector/openrouterjsoncached.php
   - connector/openrouterjsoncached_helpers.php
   - connector/openrouterjsoncached_verbose.php

   ADDITIONALS FILES (3 files - enhanced features):
   - prompts/dialogue_prompt.php
   - lib/data_functions.php
   - lib/chat_helper_functions.php

2. CONDITIONAL UI TOGGLE

   The "Minimize Quality Instructions" toggle is now conditionally displayed:
   - Shows only when prompts/dialogue_prompt.php contains the marker
     "CHIM_CACHED_FEATURE: MINIMIZE_QUALITY_PROMPT"
   - Hidden if vanilla dialogue_prompt.php is present
   - Prevents confusing UI options that do nothing

3. REMOVED ui/events-memories.php

   This file has been removed from the package:
   - Its change was backwards-compatible (handles array content format)
   - Not strictly required for cached connector functionality
   - Reduces files to maintain

TECHNICAL DETAILS
-----------------

Modified Files:
- ui/core/llm_connectors.php
  * Added conditional check for minimize_quality_prompt toggle

  * Added marker comment: "CHIM_CACHED_FEATURE: MINIMIZE_QUALITY_PROMPT"

Removed Files:

INSTALLATION SCENARIOS
----------------------

Scenario 1: Full Installation (Recommended)
- Install all CORE + ADDITIONALS files
- All features available

Scenario 2: Core Only (Quick Recovery After HerikaServer Update)
- Install only CORE files (6 files)
- Connector works with main features
- "Minimize Quality" toggle hidden
- Simple format sentences batch slightly
- Asterisk stripping bug present

Scenario 3: Staged Update
1. Install CORE files to restore connector
2. Install ADDITIONALS when time permits
3. UI automatically shows features as they're installed
