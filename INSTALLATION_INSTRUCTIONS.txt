CHIM Cached Connector v1.5.3 - Installation Instructions
========================================================

IMPORTANT: READ BEFORE INSTALLING
----------------------------------
This connector provides advanced caching, thinking/reasoning support,
flexible quality instruction control, and true sentence-by-sentence
streaming for simple format.

v1.5.3 is compatible with CHIM 2.3.3.

REQUIREMENTS
------------
- CHIM 2.3.3 or compatible version
- PHP 7.4 or higher
- OpenRouter, Anthropic, OpenAI, or Gemini API access
- Write permissions to CHIM installation directory

INSTALLATION STEPS
------------------

1. BACKUP YOUR CURRENT INSTALLATION
   Before installing, backup these directories:
   - connector/
   - lib/
   - lib/core/
   - ui/core/
   - conf/
   - ext/

2. INSTALL CORE FILES (Required)
   Copy these files maintaining directory structure:

   connector/openrouterjsoncached.php
   connector/openrouterjsoncached_helpers.php
   conf/conf_schema.json
   lib/core/llm_connector.class.php
   ui/core/llm_connectors.php

3. INSTALL NEW FILES (Safe - no overwrites)
   These files are added alongside existing files:

   lib/reasoning_helpers.php
   ext/cached_connector/dialogue_prompt.php

   NOTE: You may need to create the ext/cached_connector/ directory.

4. INSTALL UPSTREAM OVERWRITES (Review first)
   These replace CHIM 2.3.3 upstream files. All modifications are
   clearly marked with BEGIN/END CACHED CONNECTOR comments.

   lib/data_functions.php
   lib/chat_helper_functions.php

   If you have custom modifications to these files, review the
   marked sections and merge manually.

5. VERIFY INSTALLATION
   - Access CHIM web interface
   - Navigate to LLM Connectors configuration
   - Create or edit a connector
   - Select "openrouterjsoncached" from the Driver dropdown
   - Verify caching settings section appears
   - Version should display as v1.5.3

6. CONFIGURE CONNECTOR
   a. Basic Settings:
      - Set connector name
      - Select service (OpenRouter/OpenAI/etc)
      - Enter API URL and credentials
      - Choose model

   b. Caching Settings:
      - Provider Caching Type: Select your provider
      - Response Format: Choose JSON or Simple
      - Uncached Dialogue Count: Default 4

   c. Thinking/Reasoning Settings:
      - Toggle Thinking: Check to enable reasoning
      - Thinking Tokens: Set max tokens (default 1000)
      - Effort Level: Choose minimal/low/medium/high

   d. New in v1.5.3:
      - Disable Refusal Filter: ON by default (recommended)
        Prevents false-positive response cutoffs for Gemini/Palmyra
      - Preserve Asterisk Content: OFF by default
        Keeps text between asterisks (strips * characters only)

   e. Quality Instructions:
      - Minimize Quality Instructions: ON by default for cached connector
        Uses shorter prompts for advanced models (token savings)

   f. Custom Instructions:
      - Custom System Instruction: Appears before dialogue history
      - Custom Last Instruction: Appears after dialogue history

TROUBLESHOOTING
---------------

Issue: Responses cut off mid-sentence (Gemini, Palmyra)
Solution: Ensure "Disable Refusal Filter" is checked (ON).
The upstream refusal filter triggers on common RPG dialogue words.

Issue: Asterisk content stripped from output
Solution: Enable "Preserve Asterisk Content" in connector settings.

Issue: <think> or <thinking> tags appear in NPC dialogue
Solution: Ensure lib/reasoning_helpers.php is installed.
The connector loads it automatically.

Issue: "Minimize Quality Instructions" toggle not visible
Solution: Ensure ext/cached_connector/dialogue_prompt.php is installed.
The UI checks for the CHIM_CACHED_FEATURE marker in this file.

Issue: Fatal error on pages with location data
Solution: Ensure the modified lib/data_functions.php is installed.
This fixes an upstream LOCATION_BLACKLIST bug in CHIM 2.3.3.
