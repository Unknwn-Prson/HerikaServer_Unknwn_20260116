CHIM Cached Connector v1.3.5 - Package Contents
===============================================

This package is split into CORE and ADDITIONALS for easier maintenance
when HerikaServer updates. The CORE files are the minimum required to
run the cached connector. ADDITIONALS provide enhanced features.

PACKAGE STRUCTURE
-----------------

CORE FILES (Required - Minimum for connector to function):
- conf/conf_schema.json          - Connector registration
- lib/core/llm_connector.class.php - Connector instantiation
- ui/core/llm_connectors.php     - Configuration UI
- connector/openrouterjsoncached.php - Main connector
- connector/openrouterjsoncached_helpers.php - Helper functions
- connector/openrouterjsoncached_verbose.php - Verbose variant

ADDITIONALS FILES (Optional - Enhanced features):
- prompts/dialogue_prompt.php    - Minimize Quality Instructions feature
- lib/data_functions.php         - Immediate sentence streaming (simple format)
- lib/chat_helper_functions.php  - Asterisk/dash preservation fix

DOCUMENTATION:
- CHANGELOG.txt
- CLAUDE_changelog.md
- PACKAGE_CONTENTS.txt (this file)
- connector/OPENROUTERJSONCACHED_README.md

CORE vs ADDITIONALS EXPLAINED
-----------------------------

CORE FILES enable:
- Connector appears in LLM connector dropdown
- Provider caching (Anthropic, OpenAI, Gemini)
- Response format selection (JSON / Simple)
- Thinking/Reasoning toggle
- Custom system/last instructions
- All UI settings save and load correctly

ADDITIONALS enable:
- Minimize Quality Instructions toggle (hidden if not installed)
- Immediate sentence streaming for simple format
- Asterisk/dash preservation in sentence splitting (bug fix)

CONDITIONAL UI BEHAVIOR
-----------------------

The "Minimize Quality Instructions" toggle in the UI is CONDITIONALLY
displayed based on whether the additionals are installed:

- If prompts/dialogue_prompt.php contains the marker comment
  "CHIM_CACHED_FEATURE: MINIMIZE_QUALITY_PROMPT", the toggle shows
- If vanilla dialogue_prompt.php is present, the toggle is hidden
- This prevents UI options that do nothing from confusing users

INSTALLATION SCENARIOS
----------------------

Scenario 1: Full Installation (Recommended)
- Install all CORE + ADDITIONALS files
- All features available

Scenario 2: Core Only (Quick HerikaServer Update Recovery)
- Install only CORE files
- Connector works with all main features
- "Minimize Quality" toggle hidden (feature not available)
- Simple format sentences batch slightly (75-char minimum)
- Asterisk stripping bug present (cosmetic issue)

Scenario 3: Staged Update After HerikaServer Update
1. First: Install CORE files to restore connector functionality
2. Later: Install ADDITIONALS when time permits
3. UI automatically shows/hides features based on what's installed

FILE DESCRIPTIONS
-----------------

CORE Files:

- conf/conf_schema.json
  Registers the cached connector options in CHIM's configuration system

- lib/core/llm_connector.class.php
  Adds connector instantiation (else-if branches for cached connectors)

- ui/core/llm_connectors.php (v1.3.5)
  Configuration UI with conditional "Minimize Quality" toggle
  Shows toggle only when additionals are installed

- connector/openrouterjsoncached.php (v1.3.5)
  Main connector: API communication, caching, thinking, streaming

- connector/openrouterjsoncached_helpers.php
  Format building, simple format parsing, sentence splitting

- connector/openrouterjsoncached_verbose.php (v1.3.5)
  Verbose variant with additional logging

ADDITIONALS Files:

- prompts/dialogue_prompt.php
  Contains "CHIM_CACHED_FEATURE: MINIMIZE_QUALITY_PROMPT" marker
  Enables shorter prompts for advanced models (token savings)

- lib/data_functions.php
  Bypasses 75-char MINIMUM_SENTENCE_SIZE for simple format
  Enables immediate sentence streaming

- lib/chat_helper_functions.php
  Fixed regex preserves asterisks, dashes, hashes, at-signs
  Benefits ALL connectors, not just cached
