WHAT EACH CATEGORY MEANS
-------------------------

CORE FILES: The connector itself plus its registration in CHIM's systems.
These are the minimum required files. Without them, the connector does not
appear in the UI and cannot be used.

NEW FILES: Files that are added alongside existing CHIM files. They do NOT
replace or modify any upstream file. Safe to install without risk.

UPSTREAM OVERWRITES: Modified versions of CHIM 2.3.3 files. These contain
small, clearly marked modifications. Installing them replaces the upstream
version. Each modification is bracketed with:
  // --- BEGIN CACHED CONNECTOR MODIFICATION ---
  // --- END CACHED CONNECTOR MODIFICATION ---

INSTALLATION SCENARIOS
----------------------

Scenario 1: Full Installation (Recommended)
- Install ALL files (Core + New + Overwrites)
- All features available

Scenario 2: Core + New Files Only (Safe, Partial Features)
- Install Core files + New files (no upstream overwrites)
- Connector works with main features
- Missing: immediate simple-format streaming, PRESERVE_ASTERISKS,
  LOCATION_BLACKLIST fix

Scenario 3: Quick Restore After CHIM Update
1. Install Core files to restore connector
2. Install New files (safe, no conflicts)
3. Install Overwrites after reviewing CHIM changes
